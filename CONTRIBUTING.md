# Contributing

Thank you for helping improve Awesome Video Understanding.

## Before submitting

1. Search the README to make sure the work is not already listed.
2. Confirm that the paper is directly related to video understanding, Video-LLMs, their training, or evaluation.
3. Prefer the official paper, code, model, dataset, and project links.
4. Add the work to the most specific existing category; propose a new category only when necessary.
5. Explain in one concise sentence why the work is useful or distinctive.

## Entry style

Use this format for list entries:

```markdown
- **Project Name** — One sentence explaining its distinctive contribution. [📄](paper-url) [💻](code-url) [🤗](model-or-data-url)
```

Use this format for table entries:

```markdown
| **Project Name** | Primary focus | Evaluation format | [📄](paper-url) [💻](code-url) |
```

Omit unavailable links instead of adding placeholders. Descriptions must end with a period. Do not use tracking URLs or URL shorteners.

## Pull requests

- Keep each pull request focused on one topic or a small related group of entries.
- Briefly state which category changed and why each addition belongs there.
- Do not reorder unrelated entries.
- Ensure the Markdown renders correctly and all new links resolve.

By contributing, you agree that your contribution is released under CC0 1.0.
